# 阶段七实验报告：120 题多模态 RAG 对照实验

## 1. 实验问题

本实验回答三个问题：

1. BM25、`bge-m3` 稠密检索和 RRF 混合检索在相同证据库上的表现如何？
2. 引入检索上下文后，真实模型的闭集问答准确率能提升多少？
3. 系统在跨文档、拒答、引用质量、时延和 Token 消耗方面表现如何？

## 2. 实验设置

- 数据：12 份合成项目档案、48 个证据块、120 个问题。
- 类型：文本 25、表格 20、图像语义 20、公式 15、跨文档 20、拒答 20。
- 难度：easy / medium / hard 各 40 题。
- 检索：BM25、`bge-m3` dense、RRF hybrid，统一取 Top-5。
- 生成：真实 `deepseek-flash` API，temperature=0。
- 对照：Hybrid RAG 与不给文档的 no-RAG 闭卷基线，各 120 次请求。
- 判分：预标注关键词规则；公式比较忽略空白；拒答题必须包含明确的“未提供”。
- 统计：二项比例使用 95% Wilson 区间，系统比较使用精确双侧 McNemar 检验。

## 3. 检索结果

| 策略 | Precision@1 | Recall@1 | Recall@3 | Recall@5 | MRR | nDCG@5 |
|---|---:|---:|---:|---:|---:|---:|
| BM25 | 93.33% | 88.33% | 100.00% | 100.00% | 96.67% | 97.96% |
| Dense (`bge-m3`) | 92.50% | 85.83% | 95.83% | 97.92% | 95.65% | 95.38% |
| Hybrid RRF | **96.67%** | **90.00%** | 97.50% | 99.58% | **98.06%** | **98.21%** |

结论：Hybrid RRF 的首位命中、MRR 和 nDCG 最优，适合作为生成阶段默认策略。BM25 的 Recall@5 为 100%，略高于 Hybrid 的 99.58%；原因是基准问题包含项目名、传感器编号等精确词法锚点。Dense 的主要失分来自跨文档问题，其跨文档 Recall@5 为 87.50%，Hybrid 融合后提升至 97.50%。

## 4. 生成结果

| 指标 | Hybrid RAG | no-RAG |
|---|---:|---:|
| 总体准确率 | **99.17% (119/120)** | 16.67% (20/120) |
| 可回答问题准确率 | **99.00%** | 0.00% |
| 拒答准确率 | 100.00% | 100.00% |
| 拒答题幻觉率 | 0.00% | 0.00% |
| 平均时延 | 1148.12 ms | 1271.46 ms |
| P95 时延 | 1732 ms | 1923 ms |
| Token 总量 | 52,909 | 27,414 |

Hybrid RAG 相对 no-RAG：

- 绝对准确率提升 **82.50 个百分点**；
- 相对准确率提升 **495.00%**；
- RAG 准确率 95% Wilson 区间为 **[95.43%, 99.85%]**，no-RAG 为 **[11.06%, 24.35%]**；
- McNemar 不一致样本为 99:0，精确双侧 `p = 3.16e-30`，差异显著。

no-RAG 的 20 个正确样本全部为拒答题，说明模型按要求承认缺少私有档案，但无法回答 100 个有明确档案依据的问题。

## 5. 分组结果与错误分析

Hybrid RAG 在文本、表格、图像语义、公式和拒答五类上均达到 100%；跨文档为 95%（19/20）。按难度统计，easy 与 medium 均为 100%，hard 为 97.50%。

唯一错误为 `cross-05-gateway-sensor`。系统正确检索到 Ember 的图像证据，但 Top-5 未包含 Fjord 的表格证据，导致只回答出视觉网关，未回答传感器编号。该错误与 Hybrid 的跨文档 Recall@5 非满分一致，说明瓶颈在检索而不是生成。

## 6. 引用与效率

- 引用召回率：**99.58%**，与 Hybrid Recall@5 一致。
- 引用精确率：**88.61%**。模型通常能引用正确证据，但有时会把 Top-5 中辅助证据一并列出。
- RAG 平均时延比 no-RAG 低 123.34 ms，但两组请求并发执行，不能据此断言 RAG 天生更快。
- RAG Token 是 no-RAG 的 1.93 倍，这是注入 Top-5 上下文带来的成本。

## 7. 有效性边界

- 数据是为项目构造的闭集基准，不代表公开真实世界数据分布。
- “图像”类评测的是解析后的图像语义证据，不含本轮 OCR/VLM 解析误差；端到端文件解析已在之前阶段单独验证。
- 关键词判分可复现且低成本，但不能完全替代人工评价或独立 LLM-as-Judge。
- 拒答基线被明确告知无外部资料，因此其 0% 幻觉率反映的是受控提示下的安全行为。
- 仅运行一次 temperature=0 的完整生成实验；后续应增加多轮重复和扰动数据以估计方差。

## 8. 结论

在该 120 题闭集基准上，Hybrid RRF 提供了最佳综合排序质量，真实 RAG 系统达到 99.17% 准确率，相比 no-RAG 提升 82.50 个百分点。实验同时定位到一个可复现的跨文档检索漏召回案例，为下一阶段的查询拆分、多跳检索和 reranker 优化提供了明确目标。

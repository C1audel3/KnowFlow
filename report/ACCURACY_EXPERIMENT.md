# KnowFlow RAG 准确率对照实验

> 实验日期：2026-09-17
> 模型：DeepSeek V4.1 Flash（API 模型名 `deepseek-flash`）
> 原始结果：[`artifacts/accuracy_experiment.json`](./artifacts/accuracy_experiment.json)

## 1. 实验问题

验证引入 KnowFlow 多模态知识库后，对文档事实问答的准确率是否显著高于同一模型在没有知识库上下文时的表现。

本实验衡量的是当前固定合成文档上的**闭集事实准确率**，不是模型在开放领域的通用准确率。

![准确率对照图](../assets/accuracy_experiment.svg)

## 2. 实验设计

采用同模型配对消融设计：

| 项目 | KnowFlow RAG 组 | 无 RAG 基线组 |
|---|---|---|
| 模型 | `deepseek-flash` | `deepseek-flash` |
| 温度 | 0 | 0 |
| 问题 | 同一组 16 题 | 同一组 16 题 |
| 文档上下文 | LightRAG `mix` 检索上下文 | 无文档、无检索上下文 |
| 调用方式 | FastAPI `/query` 的真实回答 | DeepSeek Chat Completion 真实 API |
| 评分 | 预先固定的参考答案规则 | 同一规则 |

16 题覆盖：文本 4 题、表格 3 题、图片 3 题、公式 2 题、跨文档 2 题、拒答 2 题。参考答案和关键词规则在调用无 RAG 基线前写入 `data/evaluation/accuracy_experiment.jsonl`，实验后未按输出修改。

RAG 组使用阶段 5 第一轮保存的 16 个真实 HTTP 回答；无 RAG 组重新发起 16 次真实 DeepSeek API 调用。基线系统提示明确禁止在缺少合成资料时猜测，从而将“安全拒答”和“事实回答”区分开。

## 3. 准确率定义

每题只产生一次二元判断：

```text
Accuracy = 正确回答数 / 总问题数
```

正确条件由三类预注册规则组成：

- `expected_keywords`：指定事实必须全部出现。
- `expected_any`：允许中英文或同义表达，至少出现一个。
- `forbidden_keywords`：拒答题不得出现明确的错误归因或虚构金额。

整体准确率同时报告 Wilson 95% 置信区间。两组使用相同题目，因此使用双侧精确 McNemar 检验比较配对正确性。

## 4. 实验结果

### 整体结果

| 系统 | 正确/总数 | 准确率 | Wilson 95% CI | Macro Accuracy |
|---|---:|---:|---:|---:|
| KnowFlow RAG | 16/16 | **100.00%** | 80.64%～100.00% | 100.00% |
| 无 RAG DeepSeek | 4/16 | **25.00%** | 10.18%～49.50% | 33.33% |

KnowFlow RAG 相比无 RAG 基线提升 **75 个百分点**。12 个配对差异全部表现为“RAG 正确、基线错误”，没有“RAG 错误、基线正确”的样本。双侧精确 McNemar 检验结果：

```text
p = 0.000488
```

在当前固定测试集上，可以拒绝“两组配对正确率相同”的原假设。

### 分类型结果

| 类型 | 题数 | KnowFlow RAG | 无 RAG基线 |
|---|---:|---:|---:|
| 文本事实 | 4 | 100% | 0% |
| 表格事实 | 3 | 100% | 0% |
| 图片事实 | 3 | 100% | 0% |
| 公式 | 2 | 100% | 100% |
| 跨文档 | 2 | 100% | 0% |
| 拒答 | 2 | 100% | 100% |

无 RAG 模型答对的 4 题是两道通用 F1 知识题和两道资料缺失拒答题；对于项目名称、负责人、标签、传感器数值、图片代码和跨文档组合等文档专有事实，基线为 0/12，RAG 为 12/12。

实验后对两组共 32 个回答进行了逐题人工复核，复核结果与自动规则分数一致。该复核由项目开发者完成且不是盲评，因此只作为规则正确性的辅助检查，不作为独立人工评测。

## 5. 可复现方式

实验输入哈希：

```text
bbf79e02d88a1302b8618c611ca6ec2811130d9653e98bfed69855806a644f98
```

配置 `.env` 后执行：

```bash
python -m scripts.accuracy_experiment
```

脚本会读取：

- `data/evaluation/accuracy_experiment.jsonl`：问题、参考答案和评分规则。
- `report/artifacts/phase5_results.json`：KnowFlow RAG 第一轮真实回答。

然后真实调用 DeepSeek API 生成无 RAG 回答，并写入 `report/artifacts/accuracy_experiment.json`。结果文件保存模型名、温度、完整基线提示词、数据集哈希、逐题原始回答、评分详情、置信区间和显著性检验，但不保存 API Key 或 API 地址。

实验代码新增 9 个自动化测试；项目全量回归结果为：

```text
479 passed, 1 skipped, 1 warning
```

## 6. 结论

在这组以合成多模态文档为依据的 16 题闭集实验中，KnowFlow 将同一模型的准确率从 25% 提升到 100%，提升 75 个百分点。主要增益来自模型无法仅凭参数知识回答的文本、表格、图片和跨文档专有事实；通用公式知识和安全拒答不依赖 RAG 也能完成。

适合在简历中表述为：

> 设计同模型 RAG 消融实验，在 16 题闭集多模态事实集上，KnowFlow 准确率达到 100%，较无 RAG 的 DeepSeek 基线 25% 提升 75 个百分点（双侧精确 McNemar，p=0.000488）。

## 7. 有效性限制

- 样本只有 16 题，100% 准确率的 Wilson 下界仍只有 80.64%。
- 文档和题目均为项目合成样例，不能外推到开放领域或真实企业文档。
- 自动规则适合确定性事实，但不能完整判断解释质量、引用质量或复杂同义表达。
- RAG 回答来自阶段 5 已保存的一轮真实结果，基线回答在本次实验生成；两组不是同一时间调用。
- 两组生成提示并非逐字相同：RAG 使用 LightRAG 检索生成提示，基线使用明确的闭卷提示。这是“有无检索上下文”的系统级消融，不是纯提示词实验。
- 当前结果应与更大测试集、人工盲评和引用准确率结合后再作更广泛结论。

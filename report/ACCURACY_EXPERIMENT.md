# KnowFlow RAG 多指标对照实验报告

> 实验日期：2026-09-17
> 模型：DeepSeek V4.1 Flash（API 模型名 `deepseek-flash`）
> 原始结果：[`artifacts/accuracy_experiment.json`](./artifacts/accuracy_experiment.json)

## 1. 实验目标

验证引入 KnowFlow 多模态知识库后，同一个模型对文档事实的回答是否比无知识库时更准确，并从准确性、稳定性、效率和资源使用四个维度进行量化。

本实验衡量当前固定合成文档上的**闭集事实问答能力**，不是模型在开放领域的通用能力。

![KnowFlow 多指标实验结果](../assets/accuracy_experiment.svg)

## 2. 实验设计

采用同模型、同问题、两轮重复的配对消融设计：

| 项目 | KnowFlow RAG 组 | 无 RAG 基线组 |
|---|---|---|
| 模型 | `deepseek-flash` | `deepseek-flash` |
| 温度 | 0 | 0 |
| 问题 | 16 题 × 2 轮 | 16 题 × 2 轮 |
| 文档上下文 | LightRAG `mix` 检索上下文 | 无文档、无检索上下文 |
| 真实回答数 | 32 | 32 |
| 调用方式 | FastAPI `/query` 保存结果 | DeepSeek Chat Completion 实时 API |
| 评分 | 同一预注册参考答案规则 | 同一预注册参考答案规则 |

实验共分析 **64 个真实系统回答**。问题分布为文本 4 题、表格 3 题、图片 3 题、公式 2 题、跨文档 2 题、拒答 2 题。

参考答案与关键词规则在无 RAG 调用前写入 `data/evaluation/accuracy_experiment.jsonl`，实验后没有根据模型输出修改。RAG 组使用阶段 5 保存的两轮真实 HTTP 回答；基线组本次重新执行两轮共 32 次真实 DeepSeek API 调用。

## 3. 指标定义

### 准确性

- **Micro Accuracy**：所有题次中正确回答的比例。
- **Macro Accuracy**：六个问题类别准确率的算术平均。
- **Answerable Accuracy**：排除两道拒答题后，实际有文档答案的问题准确率。
- **Refusal Accuracy**：资料确实未提供时，模型正确拒答且不虚构的比例。
- **Per-type Accuracy**：文本、表格、图片、公式、跨文档和拒答分别统计。

每题按预注册的 `expected_keywords`、`expected_any` 和 `forbidden_keywords` 产生一个二元正确性判断。

### 统计比较

- Wilson 95% 置信区间。
- 第一轮配对结果的双侧精确 McNemar 检验。
- 绝对准确率提升、准确率倍数、相对准确率提升和错误减少率。

### 稳定性

- **Correctness Agreement**：同一题两轮的正确/错误结论是否一致。
- **Exact Answer Match**：忽略多余空白后，两轮答案文本是否完全相同。
- 两轮准确率范围。

### 效率与资源

- 平均、P50、P95、最小和最大端到端延迟。
- 平均与 P50 回答字符数。
- 无 RAG API 返回的 Prompt、Completion 和 Total Tokens。

RAG 延迟来自重复问题的缓存命中，基线延迟来自实时生成，两者口径不同，因此不计算“加速比”。

## 4. 核心准确率结果

| 系统 | 正确/总数 | Micro Accuracy | Wilson 95% CI | Macro Accuracy |
|---|---:|---:|---:|---:|
| KnowFlow RAG | 32/32 | **100.00%** | 89.28%～100.00% | 100.00% |
| 无 RAG DeepSeek | 8/32 | **25.00%** | 13.25%～42.11% | 33.33% |

效果量：

| 指标 | 结果 |
|---|---:|
| 绝对准确率提升 | **+75 个百分点** |
| 准确率倍数 | **4.00×** |
| 相对准确率提升 | **300%** |
| 错误减少率 | **100%** |
| McNemar 双侧精确检验 | **p = 0.000488** |

第一轮共有 12 个不一致配对，全部为“RAG 正确、基线错误”，没有“RAG 错误、基线正确”的样本。在当前固定测试集上，可以拒绝两组配对正确率相同的原假设。

## 5. 分场景结果

### 可回答与拒答

| 场景 | KnowFlow RAG | 无 RAG 基线 |
|---|---:|---:|
| 有文档答案的问题 | **28/28，100%** | **4/28，14.29%** |
| 资料缺失拒答 | **4/4，100%** | **4/4，100%** |

无 RAG 基线在拒答任务上表现正常，但无法回答文档专有事实。它答对的 4 个可回答题次全部来自两轮通用 F1 公式问题。

### 分类型准确率

| 类型 | 题次数 | KnowFlow RAG | 无 RAG 基线 |
|---|---:|---:|---:|
| 文本事实 | 8 | 100% | 0% |
| 表格事实 | 6 | 100% | 0% |
| 图片事实 | 6 | 100% | 0% |
| 公式 | 4 | 100% | 100% |
| 跨文档 | 4 | 100% | 0% |
| 拒答 | 4 | 100% | 100% |

对项目名称、负责人、验收标签、传感器数值、图片代码和跨文档组合等专有事实，RAG 为 24/24，基线为 0/24。

## 6. 跨轮稳定性

| 指标 | KnowFlow RAG | 无 RAG 基线 |
|---|---:|---:|
| 第一轮准确率 | 100% | 25% |
| 第二轮准确率 | 100% | 25% |
| 准确率范围 | 0 | 0 |
| 正确性一致率 | 100% | 100% |
| 答案文本完全一致率 | 100% | 0% |

两组的正确性结论跨轮完全稳定。基线的文本完全一致率为 0%，表示自然语言措辞发生变化，但没有改变对错结论。RAG 的 100% 文本一致率主要来自 LightRAG 查询缓存，不能据此推断模型自由生成时完全确定。

## 7. 延迟、回答长度与 Token

### 延迟

| 系统与口径 | Mean | P50 | P95 | Min | Max |
|---|---:|---:|---:|---:|---:|
| RAG，缓存命中 | 131.88 ms | 125.50 ms | 137.45 ms | 112 ms | 343 ms |
| 无 RAG，实时 API | 1460.47 ms | 1315.50 ms | 2466.75 ms | 884 ms | 3108 ms |

这张表只描述各自运行状态，不能证明 RAG 比无 RAG 更快。公平的速度对照需要清空并隔离缓存、使用相同网络时段并重复首次查询。

### 回答长度

| 系统 | 平均字符数 | P50 字符数 |
|---|---:|---:|
| KnowFlow RAG | 390.19 | 357.00 |
| 无 RAG基线 | 38.84 | 33.50 |

RAG 回答包含解释和参考来源，因此明显更长。回答长度不代表质量，只用于描述输出风格和估算成本。

### 无 RAG API Token 用量

| 指标 | 结果 |
|---|---:|
| 有 Usage 数据的请求 | 32/32 |
| Prompt Tokens | 2,796 |
| Completion Tokens | 5,242 |
| Total Tokens | 8,038 |
| 每请求平均 Total Tokens | 251.19 |

Token 数使用 DeepSeek API 原始 `usage` 字段，其中 Completion Tokens 可能包含服务端计入的推理 Token。由于阶段 5 的 RAG API 没有保存 Token usage，本报告不进行两组成本比较，也不根据可能变化的价格估算金额。

## 8. 人工复核

实验后对两组两轮共 64 个回答进行了逐题检查，人工复核与自动规则的正确/错误结论一致。复核由项目开发者完成且不是盲评，因此仅用于确认规则没有明显误判，不作为独立人工评测指标。

## 9. 可复现方式

数据集 SHA-256：

```text
bbf79e02d88a1302b8618c611ca6ec2811130d9653e98bfed69855806a644f98
```

配置 `.env` 后执行：

```bash
python -m scripts.accuracy_experiment --rounds 2
```

脚本读取固定数据集和阶段 5 两轮 RAG 原始回答，再真实调用 DeepSeek API 生成两轮无 RAG 回答。输出保存模型名、温度、完整基线提示词、数据集哈希、逐题回答、每轮分数、延迟、Token、稳定性、置信区间和显著性检验；不会保存 API Key 或服务地址。

## 11. 结论与简历表述

在 16 题、两轮、共 64 个真实系统回答的合成闭集实验中，KnowFlow RAG 的事实准确率为 100%，无 RAG 同模型基线为 25%，提升 75 个百分点；可回答问题准确率由 14.29% 提升至 100%，两轮正确性一致率均为 100%。

推荐简历表述：

> 设计两轮同模型 RAG 消融实验，分析 64 个真实回答；KnowFlow 在 16 题闭集多模态事实集上准确率达 100%，较无 RAG DeepSeek 基线 25% 提升 75 个百分点，可回答题准确率由 14.29% 提升至 100%（McNemar p=0.000488）。

不要省略“16 题”“合成闭集”和“同模型基线”等限定条件。

## 12. 有效性限制

- 独立问题只有 16 个，两轮重复不能等价为 32 个独立样本；主要显著性检验只使用第一轮配对结果。
- 文档和题目均为项目合成样例，不能外推到开放领域或真实企业文档。
- 关键词规则不能完整判断解释质量、引用质量和复杂同义表达。
- RAG 与基线提示不完全相同，这是系统级“有无检索上下文”消融，而非纯提示词实验。
- RAG 回答来自已保存的缓存结果，基线在本次实验实时生成，延迟不可直接比较。
- 需要更大测试集、独立人工盲评和引用质量指标后，才能形成更强结论。
